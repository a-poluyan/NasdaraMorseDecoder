# Nasdara Morse Decoder

1. Запустите `NasdaraMorseDecoder.exe` на Windows x64. Среда .NET включена в EXE.
2. В Windows направьте звук DayZ на устройство воспроизведения по умолчанию.
3. Нажмите **«Начать прослушивание»** и включите рацию в DayZ на **80,0 МГц** в игровое ночное время.

Завершённые строки остаются в таблице после остановки и нового запуска прослушивания, пока открыто приложение. При смене устройства приложение переподключается и ищет начало новой серии.

Звёздочка заменяется цифрой, как только принятые точки и тире оставляют один вариант. Остальные элементы проверяются до подтверждения цифры. Время в колонке **«Принято»** появляется после подтверждения последней цифры кода. После паузы между сообщениями результат добавляется в историю. Все сообщения, включая повторы, идут в порядке приёма.

По умолчанию в DayZ тон Морзе звучит на частоте 980 Гц. Значение 0 включает автопоиск примерно в диапазоне 240–3000 Гц. Это частота слышимого тона, тогда как 80,0 МГц — канал игровой рации.

Аудио обрабатывается в памяти через WASAPI loopback. В захват попадает звук всех приложений на выбранном устройстве. Декодер рассчитан на фактический звук Морзе на карте Nasdara. В захваченном эфире слышимая точка длится около 0,1 с, тире — около 0,48 с. Остаток каждого временного слота передаётся тишиной.
